A personal study tracker for the **ICAI CA Intermediate** exam, built as a single self-contained web page. No sign-up, no server — everything is saved in your own browser.

**▶ Live demo:** https://tejnanichandan-ctrl.github.io/ca-tracker/

---

## Features

- **Today's plan** — daily task list and time blocks for CA work, college and other commitments
- **Subject & lecture tracking** — mark lectures done per subject and see progress at a glance
- **Exam countdown** — days left to the attempt, always on screen
- **Study timer** — log focused study sessions
- **Streaks, XP & levels** — light gamification to keep a daily habit going
- **Test log** — record RTP, MTP and PYQ attempts and scores
- **Calendar** — week, month, agenda and grid views, with export to `.ics` for Google / Apple Calendar
- **Resources** — links to ICAI study material, free resources, teacher notes and file folders
- **Your data, portable** — export / import as JSON, or export the dashboard as PDF

## Tech

One `index.html` file: HTML, CSS and vanilla JavaScript, no frameworks or build step. State is stored in `localStorage`, so it works offline once loaded.

## Run locally

```bash
git clone https://github.com/tejnanichandan-ctrl/ca-tracker.git
cd ca-tracker
# open index.html in any modern browser
```
